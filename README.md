# Геоинформационные технологии

## Лабораторная работа №7 - MapGL JS API

### Описание проекта

Данный проект представляет собой веб-приложение, разработанное в рамках лабораторной работы №7 по дисциплине "Геоинформационные технологии".

Приложение демонстрирует работу с **MapGL JS API** — библиотекой для создания интерактивных карт с возможностью добавления маркеров, слоев и других геопространственных данных.
